## dependencies
- CMake >= 3.16
- C++17
- Qt 6.8.2
- OpenGL

## build
```
cd blocks
mkdir build && cd build
cmake .. -DCMAKE_PREFIX_PATH="/home/user/Qt/6.8.2/gcc_64/lib/cmake" // qt cmake path
cmake --build .
```
or open and build it via qt desktop app
